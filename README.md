
# AI-Powered Resume Builder & Analyzer (MERN)

## Project Setup

### Server Setup
```bash
cd server
npm install
cp .env.example .env
npm run dev
```

Server URL: http://localhost:5000

### Client Setup
```bash
cd client
npm install
cp .env.example .env
npm run dev
```

Client URL: http://localhost:5173

## Project
AI-Powered Resume Builder and Analyzer using MERN Stack.

## Features
- Resume Builder
- Resume Analyzer
- AI-Powered Analysis

## Technology
- MongoDB
- Express.js
- React.js
